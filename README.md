## Selected public work

### [Nexus AI Agent Framework](https://github.com/BULMKT/NexusAIAgentFramework)

A durable, auditable TypeScript runtime for production AI agents. Nexus combines human approval gates, token and cost budgets, replay, MCP support, OpenTelemetry integration, and the Open Agent Run format in a self-hosted package with zero runtime dependencies. The public release is backed by 171 automated tests and is also available as [`@nexusaiframework/runtime`](https://www.npmjs.com/package/@nexusaiframework/runtime).

### [AI Image Production](https://github.com/BULMKT/claude-code-imagegen)

A public showcase of an AI image-production workflow designed around repeatable art direction rather than one-off prompting. It documents reference-image orchestration, brand consistency, transparent-background processing through difference matting, and delivery-size optimisation.
